# SelfLearn

Ứng dụng học tập và luyện tập kiến thức được xây dựng bằng Flutter.

## Tính năng

- Quản lý chủ đề học tập.
- Tạo và nhập bộ đề bằng JSON.
- Luyện tập câu hỏi.
- Quản lý kho từ vựng.
- Lưu dữ liệu offline trên thiết bị.

## Công nghệ

- Flutter / Dart
- Riverpod
- SQLite / Drift
- Android

## Cài đặt

1. Tải file APK tại mục [Releases](../../releases).
2. Cài đặt APK trên thiết bị Android.
3. Mở ứng dụng và bắt đầu sử dụng.

## Dành cho lập trình viên

Yêu cầu Flutter SDK và Android SDK tương thích với phiên bản dự án.

```bash
flutter pub get
flutter run
```

Kiểm tra:

```bash
dart format .
flutter analyze --fatal-infos
flutter test
```
